Bitte beachte folgende wichtige Punkte:

* **Der Schaltplan und die Leiterplatte wurden noch nicht getestet.**
  Es können Fehler enthalten sein oder spätere Anpassungen notwendig werden.
* **Ich übernehme keinerlei Haftung** für Schäden, Fehlfunktionen oder sonstige Probleme, die durch die Nutzung, Nachfertigung oder Modifikation der bereitgestellten Dateien entstehen.
* **Die Nutzung erfolgt vollständig auf eigene Verantwortung.**
* **Das Design kann sich noch ändern.
  Verbesserungen oder Korrekturen werden ggf. in zukünftigen Versionen veröffentlicht.**
* **Hinweis zum SumUp-Bezahlterminal:
  Die Leiterplatte enthält mechanische oder elektrische Platzhalter, die ursprünglich für eine mögliche Anbindung eines SumUp-Bezahlterminals vorgesehen waren.
  **Diese Funktion wird weder jetzt noch zukünftig in der Software unterstützt oder implementiert.
  Eine Nutzung des SumUp-Terminals mit dieser Hardware ist ausgeschlossen.****

Wenn du Fehler findest oder Verbesserungsvorschläge hast, freue ich mich über ein Issue.
